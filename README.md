# 📈 Investment Profit Prediction Dashboard

A Machine Learning web application that predicts company profit based on investment spending using **Multiple Linear Regression** and is deployed using **Streamlit Cloud**.

---

## 🚀 Project Overview

This project helps businesses estimate their profit based on:

- Digital Marketing Spend
- Promotion Spend
- Research Spend
- State Location

The model analyzes investment patterns and predicts estimated company profit in real time.

---

## 🎯 Features

✅ Upload-ready ML project  
✅ Data preprocessing using Pandas  
✅ Dummy Variable Encoding for categorical data  
✅ Multiple Linear Regression Model  
✅ Model Evaluation using R² Score  
✅ Real-time profit prediction  
✅ Prediction history tracking  
✅ Interactive Streamlit dashboard  
✅ GitHub + Streamlit deployment ready

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/investment-profit-prediction.git
```

Move into project folder:

```bash
cd investment-profit-prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Streamlit app:

```bash
streamlit run app.py
```
